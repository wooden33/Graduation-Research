\begin{abstract}
Large language models (LLMs) have shown promise in automated unit test generation, yet achieving high branch coverage for complex methods remains challenging. We argue that these failures stem not from limited model capability, but from a fundamental \emph{cognitive misalignment} between the information provided to the model and what is required to reach target branches. In particular, effective branch coverage requires both satisfying implicit execution constraints—often spanning multiple methods—and focusing on branch-relevant context, while existing approaches expose raw method bodies and rely on the LLM to handle both simultaneously. We propose \textsc{CogPath}, a constraint-guided context-reduction framework that addresses this issue by externalizing hidden path conditions as \emph{Constraint-Hints} and isolating branch-relevant dependencies via coverage-driven backward slicing, within an iterative generate–execute–repair loop. Evaluated on 14 Defects4J projects (2,971 methods), CogPath achieves 44.41\% average branch coverage, outperforming prior approaches by 10.2\%–23.3\%, demonstrating that aligning constraints and context with coverage objectives is critical for effective LLM-based test generation.

\end{abstract}
